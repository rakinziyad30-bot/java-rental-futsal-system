
Rental Futsal Management System

A Java-based application for managing futsal field rentals using MySQL as the database.

Features

- User Login and Registration
- Admin and Customer Roles
- Futsal Field Management
- Field Booking System
- Booking Information Management
- Payment Management
- MySQL Database Connection

Technologies

- Java
- MySQL
- JDBC
- Java Scanner

Project Structure

- "Main.java" – Main application and menu navigation
- "DatabaseConnection.java" – MySQL database connection
- "Lapangan.java" – Futsal field management
- "booking.java" – Booking data management

Purpose

This project was developed to practice Java Object-Oriented Programming (OOP), database integration, and CRUD operations.
